# Security policy

Please report vulnerabilities in ddnetmirror **privately** through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Supported versions: only the latest release receives security fixes.

Scope: this tool's own code and documentation. Problems in CloudVision, EOS, cEOS or Containerlab belong with their vendors or projects.

Never include CloudVision tokens, real device configs or other secrets in a report. Use synthetic data to reproduce the problem.

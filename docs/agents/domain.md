# Domain Docs

Single-context layout:

- `GLOSSARY.md` at the repo root
- `docs/adr/` at the repo root

## Consuming

Before exploring, read `GLOSSARY.md` and any `docs/adr/` entries relevant to the area. If they don't exist, proceed silently; they are created only when a term or decision is actually resolved.

Use glossary terms as defined. If your output contradicts an ADR, say so explicitly rather than silently overriding it.

## Authority

Glossary and ADRs may record established domain knowledge and approved architectural decisions, including decisions not yet implemented. They mirror decisions recorded on GitHub (cite the issue) and are never a planning tracker, backlog, or authorization to implement. `AGENTS.md` takes precedence.

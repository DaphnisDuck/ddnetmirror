# Triage Labels

Maps the skills' five triage roles to this repo's GitHub labels.

| Role in skills    | Label in this repo | Meaning                                   |
| ----------------- | ------------------ | ----------------------------------------- |
| `needs-triage`    | `needs-triage`     | Maintainer needs to evaluate this issue   |
| `needs-info`      | `question`         | Waiting on reporter for more information  |
| `ready-for-agent` | `ready-for-agent`  | Specified; eligible for Dispatcher assignment |
| `ready-for-human` | `ready-for-human`  | Requires human implementation             |
| `wontfix`         | `wontfix`          | Will not be actioned                      |

`ready-for-agent` is not authorization to start work. The Dispatcher assigns work (see `AGENTS.md`).
